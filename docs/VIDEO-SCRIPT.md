## Sources for each claim
- "more than twice the old rule": 0.862 vs 0.391 held-out CinC 2015 (`docs/evidence/ML-RESULTS.md`). "eighty-five percent" / "fewer than three percent": CinC 2015 held-out 85.1% (97/114) and 2.7% (2/74); VTaC test 84.1% (290/345) and 4.4% (6/137) at the live thresholds (`docs/evidence/raw/fatigue.txt`).
- 12-bed ward replaying PhysioNet/CinC 2015, VTaC, MIMIC-III waveforms, VitalDB (`README.md` sources). Ward clip times above use night run N; the time-to-safe median explicitly uses historical F1–F3 (`docs/evidence/WARD-RUN.md`).
- Six containers, four hardened apps; container hub: authenticated static service accounts + topic ACLs, plaintext internal MQTT, anonymous refused, 137/137 auth checks, no agents/witness; authenticated replay only 40 seconds (`docs/evidence/CONTAINERS.md`, `docs/evidence/raw/containers-auth/auth.txt`). Systemd ward: TLS 1.3, per-device dynsec, agents/witness, 15/15 security tests (`docs/evidence/SECURITY.md`). 96-bed, 3-minute brain run: median/max tick 640.44/1121.65 ms, 0 recorded drops/invalid, bundled raw logs (`docs/evidence/SCALE.md`). AI-chip second opinion shown only (`docs/evidence/ML-RESULTS.md`).

## Honesty notes
- Granite checks numbers and selected bed-status/trust claims against supplied facts; checks are heuristic and cannot establish semantic accuracy. Review the prose against the structured facts.
- A lab ward replaying real recordings; never claim a hospital deployment.
- Alarm-fatigue numbers are advice only; never say alarms are cut or silenced.
- The on-chip AI is a shown-only second opinion and is not faster than a CPU core at this model size; do not claim speed.
- B07’s 88 legacy counts per run are a counter artefact before first data; 0 empty samples after first data in all four runs (N/F1/F2/F3). Rendered-screen continuity was not measured (`docs/evidence/WARD-RUN.md`). Film observed retained values; do not claim measured zero screen-blank time.
- The witness counts broker client IDs per bed topic/window, not cryptographic identity of each frame. N caught B12 at 17:04 after build `4348467`; F2/F3 missed it (`docs/evidence/WARD-RUN.md`).
- The systemd ward (TLS 1.3, per-device dynsec, agents/witness, 15/15) and Compose stack (authenticated static service accounts + topic ACLs, plaintext internal MQTT, four hardened apps, no agents/witness, 137/137, 40-second replay only) are separate configurations (`docs/EXPLORE.md`).
